# ascii koi — everything is ascii

Two koi, one black and one white, chase each other as a yin-yang in a living pond.
From a distance it is an ink painting. Zoom in and it resolves into characters: the
fish, the eyes, the crown and the water are all ASCII, and the black koi is written in
lines of an original poem.

**Live:** https://aaravkashyap12.github.io/ascii-koi/

- Scroll / pinch: zoom in to read the water
- Drag: turn the water
- Click: drop a stone
- H: hide the interface

Built with TypeScript, Vite and WebGL 2. The per-cell ASCII render architecture is adapted
from [SiddDevZ/horizon](https://github.com/SiddDevZ/horizon) (MIT) — see
[LICENSE-THIRD-PARTY.md](LICENSE-THIRD-PARTY.md).

```
npm ci
npm run dev
```
